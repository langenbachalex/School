# Hinweise für Claude Code

## Bilder erzeugen
Bilder für die Apps mit `python3 werkzeuge/bild_erzeugen.py ZIEL.jpg "Beschreibung"` erzeugen (Pollinations.ai, kostenlos, ohne Schlüssel).
Standard ist der GLN-1-Stil (Schwarz-Weiß-Strichzeichnung, graue Schattierung, 4:3). Mit `--seed N` eine andere Variante, mit `--roh` ohne Stilvorgabe.
Das Ergebnis immer ansehen, bevor es in die App kommt: Die Szene muss eindeutig sein.
Bilder für die Leseaufgaben Klasse 9 liegen in `app/klasse9/bilder/lesen/`.
