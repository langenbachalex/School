👩‍🏫 Lehrer-Übersicht

QR-Code im Lehrer-Bereich der App (📲 QR für Lehrer) mit der Kamera scannen. Alles bleibt in diesem Browser auf diesem Gerät, es gibt keinen Server. Immer denselben Browser benutzen.

Link von Hand einfügen

Falls die Kamera den Link in einem anderen Browser öffnet: den Link kopieren und hier einfügen.

Alles löschen

Löscht alle gespeicherten Stände und Namen auf diesem Gerät.
