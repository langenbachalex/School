# Chat-Name nennen

Wenn Mr. Alex `/name` tippt oder fragt „Wie heißt du?“ / „Wie soll dieser Chat heißen?“:

1. Bestimme aus dem bisherigen Chat: die App (Kürzel `EN6`, `EN9`, `FR`, `ALLE`; mehrere mit `+`, z. B. `EN6+EN9`), den Block (zwei bis vier Wörter, wie im Ideenspeicher) und das Startdatum des Chats (`T.M.`). Ist es der Master-Chat (Planen, Entscheiden, kein Bau): Name `School · MASTER`.
2. Antworte mit höchstens drei Zeilen: dem Namen allein in einem Code-Block zum Kopieren, darunter ein Satz, worauf er sich stützt. Keine Alternativen anbieten, außer die App ist wirklich unklar.

Beispiel:
```
School · FR · Französisch-App · 7.11.
```
